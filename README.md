# MetaLab

MetaLab (ML) is an open-source platform for developing and running business applications. It takes inspiration from the development model of 1C:Enterprise while providing an independent implementation built with Go and PostgreSQL.

> MetaLab is at an early design and development stage and is not ready for production use.

## Project goals

- BSL-compatible language with Russian and English syntax.
- Metadata-driven business applications.
- A dedicated ML Studio IDE with code editing, debugging, tests and visual form design.
- Responsive browser-based ML App for desktop, tablet and mobile devices.
- PostgreSQL as the application database.
- Managed forms, documents, catalogs, registers, reports and data composition.
- Transactions, roles, data access policies and audit logs.
- HTTP/JSON integrations and optional support for local equipment through ML Agent.
- One-way import of supported 1C XML configuration exports.
- Open project files based on YAML, BSL and Git.

## Planned components

- **ML Manager** — manages the platform service and application databases.
- **ML Service** — executes BSL, serves applications and works with PostgreSQL.
- **ML Studio** — IDE for metadata, BSL, forms, debugging and testing.
- **ML App** — responsive web client for end users.
- **ML Agent** — optional bridge for printers, scanners and other local equipment.

## Current status

The high-level product requirements and development roadmap have been prepared. Implementation has not started yet.

Installation and usage instructions will be added as soon as the first working version becomes available.
